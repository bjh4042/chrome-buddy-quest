Edge로 자료를 모으고 정리하기

‘선생님과 함께 배우기 → 인터넷’에서 아래 8개 임무를 연습합니다. 먼저 연습 Wi-Fi에 연결하고 주소창에 school.example을 입력하세요.

‘다운로드할 때마다 저장 위치 묻기’를 켜면 새 파일을 받을 때마다 이번 파일의 폴더를 고릅니다. 기본 위치는 유지됩니다. 기본 폴더를 바꾸어도 기존 파일은 이동하지 않으므로, 파일 정리는 탐색기에서 별도로 연습합니다.

재연습 시 목록이 비어 있으면 즐겨찾기를 먼저 추가하거나 안내 파일을 내려받습니다. 탭 복원 전에는 사이트 탭을 하나 닫으세요. 단축키가 실제 브라우저에 적용되면 앱의 같은 메뉴 명령을 사용합니다.

여기의 저장 위치와 ‘폴더에 표시’는 앱 안의 가상 폴더·파일 탐색기를 뜻합니다. 자료를 받으면 앱 파일을 저장하고 실제 브라우저에 TXT 내보내기를 요청합니다. 실제 파일의 저장 여부와 경로는 사용 중인 브라우저의 다운로드 설정을 따릅니다. 앱 설정으로 실제 Edge·Chrome의 전역 저장 경로나 이미 받은 PC 파일은 바뀌지 않습니다.

실습할 때 알아 두세요

  • 프로그램은 바탕화면 아이콘을 두 번 누르거나 시작 메뉴에서 선택합니다.
  • 문서 도구 안의 실습 안내를 펼치면 실제 수행 결과를 확인합니다.
  • 작업 표시줄의 네트워크·스피커 묶음에서 빠른 설정을 엽니다. Wi-Fi는 옆 화살표로 연결 목록을 봅니다.
  • 우리집 WiFi의 연습용 키는 12345678, 학교 연습 Wi-Fi는 class2026입니다.
  • 실제 Windows 이모지는 Win+.입니다. 탐험대에서는 ‘이모지’ 버튼이나 표시된 대체 단축키로 연습합니다.
작성 문서와 학습 기록은 현재 브라우저에 저장됩니다. 기기를 공유하면 다음 학생도 같은 자료를 보게 됩니다. 중요한 작업은 각 프로그램의 다운로드로 보관하세요. ‘학습 기록 초기화’는 작성 문서까지 지우지 않습니다.

작은 화면에서 팝업 사용하기

사진·표·저장·암호 창은 화면 크기에 맞게 표시합니다. 위 제목과 아래 확인·저장·취소 버튼은 남고, 긴 목록과 설명만 가운데에서 스크롤합니다. 화면 키보드로 표시 영역이 줄어들면 팝업 크기도 맞춥니다. Esc로 닫거나 Tab으로 버튼을 이동할 수 있습니다.

확인한 범위

현재 24개 파일의 자동 회귀 테스트 165개와 TypeScript 검사를 통과했습니다. 저장·이동·찾기 결과를 근거로 미션을 판정하며, 기존 학습 기록도 유지합니다. 실제 수업 기기별 확인 범위는 아래 안내를 참고하세요.

지원 범위

Wi-Fi·볼륨·종료·암호·업데이트는 앱 안에서 연습하며 실제 PC에는 적용되지 않습니다. 연습용 암호는 새로고침하면 삭제됩니다. 실제 암호나 개인정보를 입력하지 마세요.

문서 백업은 탐험대 JSON입니다. Excel은 CSV, 메모장은 TXT도 제공합니다. 실제 HWP/HWPX·XLSX·PPTX 전체 호환을 제공하지 않습니다. Edge의 검색과 사이트 화면은 로컬 학습 자료입니다.

세부 기능 한도와 확인이 필요한 환경

Excel: A1~X40, 시트 12개, SUM/AVERAGE/MIN/MAX/COUNT와 기본 산술·셀 참조. PowerPoint: 최대 30장. 문서 도구별 저장 목록과 탐색기의 파일은 별도입니다. 실제 학교 PC의 화면 배율·설치 글꼴·터치 입력 차이가 있으므로 수업 전 한 번 실행해 주세요. 데스크톱 Chrome에서 브라우저 동작을 확인했으며 Edge·Safari·실물 태블릿은 별도 실기 확인이 필요합니다.
