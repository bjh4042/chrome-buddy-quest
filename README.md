## 시작 화면 Windows 11 테마 (2026-11-03)

첫 접속 화면에 Microsoft 공식 Bloom 밝은 배경과 Windows 11의 Mica 색감·Fluent 버튼을 적용했습니다. 학습 시작, 이어서 하기, 자유 연습, 교사 모드와 기록 초기화 흐름은 유지합니다. 작은 화면은 세로 스크롤로 모든 메뉴에 접근하며, 키보드 포커스와 동작 줄이기 설정을 지원합니다.

2026-11-03 검증: 자동 테스트 24개 파일·165개, TypeScript 검사와 배포 빌드 통과. Chrome iframe의 1024×600·800×600·640×480·360×640·568×320·320×360에서 가로 넘침 없이 모든 컨트롤 폭을 확보했습니다. 320×360에서 안내 펼치기와 교사용 링크로 키보드 이동을 확인했고, 기본 탐험·자유 연습·교사 모드 버튼으로 실제 화면에 진입했습니다. 실제 물리 기기의 테스트를 의미하지 않습니다.

배경 출처: [Microsoft Windows 11 공식 이미지 자료](https://news.microsoft.com/windows11-general-availability/). 로컬 파일 `src/assets/windows11-bloom-light.jpg`로 제공하므로 외부 이미지 서버에 의존하지 않습니다. Windows 11 테마를 참고한 학습용 시작 화면이며 실제 Windows 로그인 화면은 아닙니다.

## 실행과 배포

Node.js 20 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

검증 및 배포 파일 생성:

```sh
npm test
npx tsc --noEmit -p tsconfig.app.json
npm run build
npm run preview
```

`dist/` 전체를 정적 호스팅에 배포합니다. 소스 `index.html`이나 빌드 결과를 파일 탐색기에서 바로 여는 방식(file://)은 지원하지 않습니다. `index.html`은 HTTP(S)로 제공해야 합니다. npm 잠금 파일을 동기화했으며 과거의 Bun 잠금 파일은 혼용하지 않습니다. 서버·학생 계정·API 키는 필요하지 않습니다.

## 교실 운영 예시

한 차시에 모든 기능을 몰아넣지 않고 각 40분 수업으로 나누는 것을 권합니다.

1. 클릭·더블클릭·우클릭·드래그, 창 이동과 크기 조절.
2. 나의 자료 폴더 만들기 → 이름 바꾸기 → 문서 이동 → 삭제와 복원.
3. Wi-Fi·볼륨·배경 바꾸기, 연습 PIN 설정과 잠금 해제, 인터넷 주소 확인.
4. 한글의 ‘초대장 만들기’ 실습: 제목·본문·그림·표·저장.
5. Excel의 ‘우리 반 준비물 예산’: 수량×단가와 합계·서식·저장.
6. PowerPoint 3장 소개 발표: 제목·그림·테마·발표자 노트·슬라이드 쇼.
7. Edge 자료 보관: 즐겨찾기 → 안내 TXT 다운로드 → 폴더에 표시 → 문서로 이동 → 앞으로 받을 파일의 기본 위치 변경.

수업 시작 전 ‘원하는 임무 연습하기’ 또는 ‘선생님과 함께 배우기’를 선택하면 선행 임무 없이 해당 주제를 열 수 있습니다. 각 문서 도구의 실습 안내를 펼쳐 결과 확인 항목을 봅니다.

## Edge 신규 실습 8개

주소 입력 다음에 즐겨찾기 추가·즐겨찾기로 열기·파일 내려받기·받은 폴더 찾아가기·받은 파일 이동·기본 다운로드 위치 변경·페이지에서 ‘안전’ 찾기·닫은 탭 복원 임무가 이어집니다. 이름만 누르거나 메뉴만 여는 것으로 완료되지 않으며, 저장·이동·검색 결과 등 실제 앱 상태를 판정합니다.

연습 사이트 `school.example`을 열고 자료실의 안내 TXT를 받습니다. **다운로드 목록 → 폴더에 표시**는 앱 안의 파일 탐색기를 열어 해당 파일을 선택합니다. 파일을 문서로 이동한 뒤 같은 명령을 사용하면 현재 위치를 확인할 수 있습니다. **설정 및 기타 → 설정 · 다운로드 → 저장 위치 변경**은 이후 받을 파일의 기본 폴더를 정합니다. ‘다운로드할 때마다 저장 위치 묻기’를 켜면 파일마다 폴더를 선택하며, 기본 위치는 유지됩니다.

Ctrl+D(즐겨찾기 추가), Ctrl+Shift+O(즐겨찾기), Ctrl+J(다운로드), Ctrl+F(찾기), Ctrl+Shift+T(닫은 탭 복원)를 연습합니다. 실제 브라우저가 단축키를 먼저 처리할 때는 앱의 같은 메뉴 명령을 사용합니다. 단독 재연습에서 목록이 비어 있으면 먼저 사이트를 추가하거나 자료를 다운로드합니다. 세부 절차는 [Edge 실습 안내](docs/EDGE_PRACTICE_v1_1.md)에 있습니다.

## 보관과 파일 형식

학습 기록, 가상 파일, 작성 문서, 환경 설정은 현재 브라우저에 저장됩니다. 같은 기기를 공유하면 같은 저장 공간을 사용합니다. 다른 기기나 브라우저로 자동 이동하지 않습니다. 중요한 작업은 각 앱의 다운로드 기능으로 보관하세요. 저장이 차단되거나 용량이 부족하면 안내합니다.

- 한글·Excel·PowerPoint: 명시적으로 표시한 탐험대 JSON 백업 형식. 한글은 안전한 서식 데이터를 보관합니다.
- Excel: 계산 결과를 CSV로 내려받을 수 있습니다. 쉼표/줄바꿈을 올바르게 이스케이프하고 문자열의 수식 실행을 방지합니다.
- 메모장과 Edge 학습 자료: TXT.
- HWP/HWPX·XLSX·PPTX의 실제 전용 엔진이나 완전 호환을 제공하지 않습니다.
- PIN/암호는 실제 로그인 정보가 아닌 연습용이며, 메모리에만 보관하고 새로고침하면 지웁니다. 실제 암호나 개인정보를 넣지 않습니다.
- 시작 화면의 초기화는 **학습 기록과 별**을 초기화합니다. 작성 문서는 각 앱에 남습니다. 모든 자료를 지우려면 필요한 파일을 다운로드한 후 브라우저의 이 사이트 데이터 삭제를 사용합니다.

## 정확한 지원 범위

이 앱은 Windows를 실행하거나 원격 PC를 제어하지 않습니다. Wi-Fi·Bluetooth·볼륨·종료·업데이트·권한 변경은 앱 안의 학습 상태에만 적용됩니다. 실제 OS 전체·장치 드라이버·설치·시스템 관리·Windows Hello 생체 인증을 구현한 것은 아닙니다.

Edge의 즐겨찾기·다운로드 목록·저장 위치는 탐험대 안에서 관리합니다. 연습 사이트에서 다운로드하면 가상 파일을 저장하고 실제 브라우저에 TXT 내보내기를 요청합니다. 실제 파일의 저장 여부와 경로는 사용 중인 브라우저의 다운로드 설정을 따릅니다. 앱의 기본 저장 위치나 ‘파일별 위치 묻기’ 설정은 실제 Edge·Chrome의 전역 다운로드 경로를 바꾸지 않습니다.

Edge는 로컬 학습 사이트를 표시하며 실제 네이버/Bing의 최신 내용을 가져오지 않습니다. 외부 사이트처럼 보이는 화면에도 연습용임을 표시합니다. 모의 Wi-Fi가 끊겨 있으면 외부 주소 이동을 중단하고 연결 후 재시도를 제공합니다.

Excel은 A1~X40, 시트 최대 12개, SUM/AVERAGE/MIN/MAX/COUNT 및 셀 참조·기본 산술을 지원합니다. 지원하지 않는 함수는 오류로 표시합니다. PowerPoint는 최대 30장과 제목/부제/그림 중심 실습을 제공합니다. UI는 한컴오피스·Microsoft 365의 핵심 조작을 참고한 학습용 구성으로 전체 메뉴와 픽셀 단위 동일성을 보증하지 않습니다.

Windows가 먼저 처리하는 Alt+Tab, Win+. 등의 단축키는 웹페이지가 완전히 가로챌 수 없습니다. 앱의 ‘작업 보기’와 ‘이모지’ 버튼 또는 표시된 브라우저 대체 단축키를 사용합니다. 실제 Windows 이모지 단축키는 Win+.입니다.

바탕화면의 미션용 파일은 단계별 연습 대상이며, 탐색기의 일반 파일 실습과 별도로 초기화됩니다. 문서 도구의 저장 목록은 각 도구 안에서 사용하고 탐색기의 가상 파일과 자동 통합되지 않습니다.
