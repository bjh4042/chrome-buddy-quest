# Edge 자료 보관 실습

2026-11-02 · 윈도우 탐험대 v1.1 · 전체 49개 미션 중 신규 인터넷 미션 8개

‘선생님과 함께 배우기 → 인터넷’ 또는 ‘원하는 임무 연습하기’에서 선택합니다. 순서대로 탐험에서는 주소 입력 다음에 아래 8개 임무가 나옵니다. 먼저 연습 Wi-Fi에 연결하고 Edge에서 `school.example`을 여세요. 화면의 사이트는 탐험대 교육 자료입니다.

| 임무 | 직접 할 일 | 완료 확인 |
|---|---|---|
| 즐겨찾기에 추가하기 | 별 또는 Ctrl+D → 이름·폴더 확인 → 완료 | 즐겨찾기 목록에 이름과 주소가 남음 |
| 즐겨찾기로 다시 찾아가기 | 즐겨찾기 또는 Ctrl+Shift+O → 저장한 사이트 선택 | 해당 사이트 탭이 열림 |
| 파일 내려받기 | 자료실의 ‘안전한 인터넷 사용 안내.txt 다운로드’ | 다운로드 목록에 파일명·출처·앱 저장 폴더가 표시됨 |
| 다운로드한 폴더 찾아가기 | 다운로드 목록 또는 Ctrl+J → 파일의 ‘폴더에 표시’ | 앱 파일 탐색기가 열리고 실제 저장된 연습 파일이 선택됨 |
| 받은 파일 정리하기 | 파일 선택 → 잘라내기 → 문서 폴더 → 붙여넣기, 또는 이동 명령 | 파일의 현재 폴더가 바뀜. 같은 폴더에 두는 것은 이동으로 판정하지 않음 |
| 다운로드 저장 위치 바꾸기 | 설정 및 기타 → 설정 · 다운로드 → 저장 위치 변경 → 문서 등 다른 폴더 → 폴더 선택 | 이후 받는 파일의 기본 위치가 ‘다운로드’ 이외의 폴더로 바뀜 |
| 페이지 안에서 낱말 찾기 | Ctrl+F 또는 페이지에서 찾기 → ‘안전’ 입력 | 일치 항목이 한 개 이상 표시됨. 이전·다음으로 이동 가능 |
| 닫은 탭 다시 열기 | 연습 사이트의 탭 X → Ctrl+Shift+T 또는 설정 및 기타 → 닫은 탭 다시 열기 | 닫았던 사이트가 다시 활성 탭으로 열림 |

‘다운로드할 때마다 저장 위치 묻기’도 설정 · 다운로드에서 연습합니다. 켠 뒤 새 자료를 받으면 이번 파일을 저장할 폴더를 고릅니다. 이때 고른 폴더는 해당 파일에 적용되며, 기본 저장 위치는 유지됩니다. 기본 폴더 변경은 이미 받은 파일을 옮기지 않습니다.

파일을 문서 등 다른 폴더로 이동한 후 Edge 다운로드 목록의 ‘폴더에 표시’를 다시 누르면 현재 위치로 찾아갑니다. 삭제된 파일에는 위치 표시를 제공하지 않습니다. 탐색기에서 이름을 바꾸면 목록도 현재 파일명을 반영합니다.

개별 임무를 다시 연습할 때는 필요한 자료부터 준비합니다. 즐겨찾기가 없으면 먼저 사이트를 추가하고, 다운로드가 없으면 안내 파일을 받습니다. 탭 복원 전에는 연습 사이트 탭을 하나 닫습니다. 실제 브라우저가 단축키를 먼저 처리하면 앱 안의 같은 이름 메뉴나 버튼을 사용하세요.

## 앱 폴더와 실제 PC 파일

탐험대의 즐겨찾기·파일·다운로드 설정은 현재 사이트의 브라우저 저장 공간에 보관합니다. ‘폴더에 표시’는 **앱 안의 파일 탐색기**를 여는 동작입니다. 실제 Windows 파일 탐색기를 실행하거나 실제 Edge의 즐겨찾기·전역 다운로드 설정을 변경하지 않습니다.

안내 파일을 다운로드하면 앱 안의 가상 파일을 저장하고, 사용 중인 실제 브라우저에 TXT 내보내기를 요청합니다. 실제 파일의 저장 여부·위치·확인창은 그 브라우저의 설정을 따릅니다. 앱에서 기본 폴더를 ‘문서’로 정해도 실제 PC의 문서 폴더에 저장된다는 뜻은 아닙니다.

## 확인한 판정 범위

전체 자동 회귀 검사 24개 파일·165개 테스트와 TypeScript 검사를 통과했습니다. 신규 임무는 저장 성공·유효한 파일·실제 다른 폴더로 이동·찾기 결과 등 동작 근거를 확인합니다. 비슷하게 꾸민 사이트 주소, 빈 이름·파일 ID, 같은 폴더로 이동, 결과 없는 찾기는 완료로 처리하지 않습니다. 기존 미션 기록은 유지하고 추가된 임무를 이어서 수행할 수 있습니다.

작은 화면의 팝업과 실제 기기별 확인 범위는 [화면 검증 기록](RESPONSIVE_QA_v1_1.md)에 있습니다.
